# Readings

One Markdown file per reading from the ethnography and culture strand. Copy `TEMPLATE.md`, name the copy `<UNIT_ID>_<short-slug>.md`, fill in the header and the sections, and commit it. The dashboard lists every reading on the Culture view and flags dimensions where two or more readings contradict the code.

A reading is an interpretation of particular material, such as a town, a festival, a novel or a set of interviews. It does not give a score. It says whether the lived evidence supports, complicates or contradicts the current code, or shows something new. See `docs/RESEARCH_DESIGN.md` for the questions, materials, methods and quality criteria.
